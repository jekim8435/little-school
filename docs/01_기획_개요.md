## 4. 학습 설계 공통 원칙

- 별은 문제 하나가 아니라 **한 묶음(한 판·한 카테고리)을 끝내면 1개**. 틀려도 별을 빼앗지 않고, 오답 연출은 흔들림만 (03 문서 6장)
- 과목당 하루 스티커 1장. 받은 뒤에도 연습은 계속할 수 있다
- 지시문은 항상 음성으로. 아이 화면 글자는 크게, 한 화면 선택지 4개 이하 (02 문서 10장)
- 개인정보 수집·광고·외부 링크 없음 (06 문서 5장)
