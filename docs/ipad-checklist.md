> - **PC 확인**: 2026-10-21 자동 검사·PC 브라우저(1024×748, 1280×800)로 이미 확인한 것. 아이패드에서는 눈으로 한 번만 보면 된다
> - **아이패드**: 실기기에서만 확인할 수 있는 것
> - 확인하면 `[x]`, 문제가 있으면 맨 아래 ‘문제 기록’에 증상을 적는다

> 준비: 홈 화면 앱을 완전히 닫았다 연다 → 부모 모드 > 기기 정보에서 빌드 시각이 최신인지, ‘오프라인: 준비됨’인지 확인

- [x] 외부로 나가는 링크가 하나도 없다 (`tests/safety.test.ts`)
- [x] `ctx.audio.speak()`로 남은 임시 문장이 없다 (`tests/safety.test.ts`)
- [x] 모든 아이 화면(시작·허브·과목·스티커판·보상 기록·오늘 끝)이 1024×748과 1280×800에서 스크롤·넘침 없이 들어간다 — 동그라미 8개, 20칸 판 포함
- [x] 과목을 10번 열고 닫아도 이벤트·타이머가 남지 않는다(늘어난 수 0)

- [ ] `npm run voice:check` — 11번(음원 마무리)에서 만든다

## B. 설치·화면 (아이패드)

- [ ] Safari ‘홈 화면에 추가’ → 주소창 없는 전체 화면으로 실행된다. 위쪽에 흰 띠 + 검은 시계
- [ ] 기기 정보: 화면 크기 `1024 × 748`, 입력 방식 `Touch Events`, 마지막 입력 `touch`
- [ ] 비행기 모드에서 앱을 열고 샘플 과목까지 들어갈 수 있다
- [ ] 시작 버튼 후 효과음·인사 음성이 난다
- [ ] 핀치 확대, 글자 선택, 길게 눌러 메뉴, 바운스 스크롤이 일어나지 않는다(허브·과목·스티커판에서 시도)
- [ ] 정전식 펜으로도 타일·동그라미·키패드가 눌린다
- [ ] 세로로 돌리면 ‘옆으로 돌려 주세요’ 안내 + 음성. 가로로 돌리면 이어진다(학습 시간도 멈췄다 이어짐 — 부모 홈 ‘오늘 n분’으로 확인)

## C. 별·스티커 (아이패드)

- [ ] 샘플 완료 때 별이 상단 바로 날아가고, 3번째(비율 3)에 스티커가 붙는다(팡파레·음성)
- [ ] 스티커를 받은 과목은 그날 별·스티커를 더 받지 않고 `오늘 스티커 ✓`. 들어갈 때 ‘오늘 스티커는 받았어요’ 음성
- [ ] 2/3에서 날짜를 넘기면 별 2개가 남아 있다 — 설정 > 일반 > 날짜 및 시간에서 자동 설정을 끄고 내일로 바꾼 뒤 앱을 연다(끝나면 자동 설정을 다시 켠다)
- [ ] 판이 다 차면 ‘스티커판 완성!’ 축하 후 다음 판이 시작된다. 지급 전에도 새 판에 계속 쌓인다(부모 모드 > 공통 설정 > 스티커판 칸 수 5칸으로 바꾸면 빨리 확인)
- [ ] 스티커판 화면에서 손가락으로 밀기·화살표로 완성 판과 지금 판을 오간다
- [ ] 보상 지급에서 내용을 넣으면 그 판이 슬라이드에서 빠지고, 보상 기록(아이·부모 둘 다)에 다 모은 날·지급일·내용이 보인다
- [ ] 부모 보상 기록에서 내용 수정, 지급 취소가 된다

## D. 학습 시간 (아이패드)

- [ ] 기기 정보 > 점검 도구 > ‘하루 학습 시간 1분으로’ → 샘플을 1분 넘게 하면 한 판 뒤 ‘오늘 공부 끝’. 허브 타일이 잠긴 모양
- [ ] 과목 안에서 아무것도 안 해도 유예 시간(기본 5분)이 지나면 ‘오늘 공부 끝’으로 간다(유예 0분으로 바꾸면 빨리 확인)
- [ ] 부모 홈 ‘오늘 10분 더’로 풀린다. 점검이 끝나면 ‘20분으로 되돌리기’

## E. 부모 모드 (아이패드)

- [ ] 허브 오른쪽 위 3초 길게 누르기 + 곱셈 정답으로만 들어간다. 짧게 누르면 아무 일 없음. 3번 틀리면 1분 잠금
- [ ] 부모 모드에서 5분 동안 아무것도 안 하면 허브로 돌아간다. 아이 화면으로 나갔다 오면 다시 문제를 푼다
- [ ] 샘플 설정 페이지에서 동그라미 개수를 바꾸면 다음에 과목을 열 때 반영된다
- [ ] 공통 설정에서 효과음을 끄면 모든 화면에서 효과음이 나지 않고, 음성 읽기를 끄면 읽기가 멈춘다
- [ ] 4자리 암호 방식으로 바꾸고 암호를 저장하면, 다음 잠금 때 암호를 묻는다(끝나면 곱셈으로 되돌려도 됨)
- [ ] 백업 ‘복사하기’ → 메모 앱에 붙여 넣기 → 전체 초기화(확인 2번 + 곱셈) → 복원에 붙여 넣기 → 별·스티커·기록이 그대로 돌아온다
- [ ] 부모 모드 화면들이 세로로 스크롤되고, 입력칸에서 키보드가 뜬다
- [ ] 앱을 완전히 종료(앱 전환기에서 위로 밀기) 후 다시 열어도 데이터가 유지된다

## F. 아이 전용 잠금 (아이패드)

- [ ] 잠금 안내 화면이 ‘아이패드 (이 기기)’를 먼저 보여 준다
- [ ] 사용법 유도를 켠 상태에서 시작 → 허브 → 과목 → 스티커판 → 부모 모드까지 모두 정상 동작한다
- [ ] 제어 센터 ‘화면 회전 잠금’을 켜면 세로 안내가 뜨지 않는다
