## 3. 우선순위와 문서 규칙

- 충돌하면 **06 > 02 > 03 > 04 > subjects** 순으로 따른다. 과목 문서는 공통 규칙을 바꾸지 못한다 — 바꿔야 하면 공통 문서를 먼저 고친다
- 지금 기준은 본문에 적는다. 취소선·‘대체’ 메모를 쌓지 말고 본문을 고치고, 바뀐 이유는 `planning-log.md`에 남긴다
- 끝난 단계의 작업 지시·체크리스트는 `history/`로 옮긴다
- 과목을 착수하면 `subjects/후보과목.md`에서 그 과목을 `subjects/<id>.md`로 옮겨 상세화한다
