# 갤럭시 탭 S6 Lite 확인 체크리스트 (보류 중)

> 2026-10-21부터 갤럭시 탭 실기기 확인을 **보류**하고 아이패드 에어1 기준으로 먼저 진행한다.
> 갤럭시 탭이 준비되면 이 목록을 한 번에 확인하고, 문제가 나온 항목을 **일괄 수정**한다.
> 구현은 계속 명세(2-5 등)대로 갤럭시 탭 대응 코드를 넣되, 확인만 미룬다.
>
> 사용법: 단계가 진행될 때마다 이 문서 아래쪽에 확인할 항목을 덧붙인다. 확인하면 `[x]`와 결과(값·증상)를 적는다.
> 주소: https://jekim8435.github.io/little-school/

## 0. 먼저 적어 둘 값 (5:3 화면 배치 기준)

| 항목 | 값 |
| --- | --- |
| 화면 크기 (가로 × 세로, 홈 화면 앱으로 실행) | |
| 기기 배율 (`devicePixelRatio`) | |
| Chrome 버전 (설정 > Chrome 정보) | |
| One UI 버전 (설정 > 휴대전화 정보 > 소프트웨어 정보) | |

## 1. 설치·실행 (1단계 2번)

- [ ] Chrome 메뉴 > **앱 설치**(또는 홈 화면에 추가)로 아이콘이 생긴다. 이름 ‘꼬마학교’, 집 모양 아이콘이 잘리지 않는다(마스커블)
- [ ] 아이콘으로 실행하면 주소창 없이, **상태 표시줄까지 가린 전체 화면**이다 — 빈 화면의 실행 방식 `홈 화면 앱 (fullscreen)`
- [ ] 기기를 세로로 돌려도 **가로로 고정**된다
- [ ] 입력 방식 `Pointer Events`. 마지막 입력이 손가락 `touch`, S펜 `pen`으로 바뀐다
- [ ] ‘소리 확인’에서 팡파레가 난다
- [ ] 당겨서 새로고침이 일어나지 않는다
- [ ] 길게 눌러도 메뉴(복사·검색 등)가 나오지 않는다. 글자가 선택되지 않는다
- [ ] 두 손가락 확대·두 번 눌러 확대가 되지 않는다
- [ ] 한 번 연 뒤 비행기 모드에서 아이콘으로 실행해도 열린다
- [ ] 빌드 시각이 최신 배포와 같다(새 버전이 들어왔는지)

## 1-2. 공통 스타일·저장 (1단계 3번)

- [ ] 확인용 화면의 `--u` 값이 화면 높이 ÷ 768과 같다(예: 높이 800이면 약 1.04px). 글자·버튼이 넘치거나 잘리지 않는다
- [ ] 위쪽에 빈 띠(20px)가 생기지 않는다(상태 표시줄 자리는 아이패드 홈 화면 앱에서만 비움)
- [ ] 앱을 완전히 닫았다 다시 열면 ‘연 횟수’가 1씩 는다(저장 유지)
- [ ] ‘확인창’ 버튼: 확인창이 가운데 뜨고, 확인·취소·바깥 누르기 모두 닫히며 위쪽에 토스트가 뜬다
- [ ] ‘다른 화면’ → ‘준비 중’ 화면 → ‘처음으로’로 돌아온다. 뒤로 가기 버튼(안드로이드)으로도 앞 화면으로 돌아간다
- [ ] 브라우저 탭(설치 전)에서 기기를 세로로 돌리면 ‘옆으로 돌려 주세요’ 안내가 뜨고, 가로로 돌리면 사라진다

## 2. 이후 단계에서 확인할 것 (명세 13장 중 갤럭시 탭 관련)

단계가 끝날 때마다 해당 항목을 여기로 옮겨 적고 확인한다.

- [ ] 두 기기 화면 비율이 달라도 넘침·잘림 없이 한 화면에 들어간다(5:3, 높이 기준 배치 — 명세 10장). 한글 글꼴(삼성/Noto) 폭 차이로 글자가 넘치지 않는다
- [ ] 부모 모드 > 기기 정보에 화면 크기·입력 종류·펜 압력이 맞게 나온다
- [ ] 첫 실행 때 `navigator.storage.persist()` 요청이 동작한다(기기 정보의 저장 공간 항목)
- [ ] 내장 음성: 목소리 목록이 늦게 채워져도 한국어 음성으로 읽는다(`voiceschanged`)
- [ ] 세로 방향 안내 화면이 (회전 고정 때문에) 뜨지 않거나, 떠도 정상 동작한다
- [ ] 부모 모드 > 잠금 안내·설치 안내가 **갤럭시 탭 안내를 먼저** 보여 준다. 앱 고정 메뉴 이름을 실기기 One UI 문구에 맞춘다(명세 8-7)
- [ ] ‘앱 고정’ 상태에서 모든 화면이 정상 동작한다
- [ ] 스티커판 좌우 슬라이드가 손가락·S펜 모두로 된다
- [ ] 과목을 10번 열고 닫아도 느려지지 않는다
- [ ] 백업 JSON 복사·파일 내려받기가 된다. 아이패드에서 만든 백업을 복원할 수 있다(기기 간 이동)
- [ ] 공통 설정의 ‘펜으로만 쓰기’ 항목이 S펜을 한 번 쓴 뒤에만 보인다

## 3. S펜 (2단계 쓰기 과목 이후)

- [ ] S펜을 띄운 상태(호버)에서는 선이 그어지지 않는다
- [ ] 펜으로 쓰는 중 손바닥이 닿아도 선이 생기지 않는다. 펜을 쓴 뒤 2초 안의 손가락 터치는 획을 시작하지 않는다
- [ ] ‘펜으로만 쓰기’를 켜면 손가락으로는 써지지 않는다
- [ ] 쓰기 캔버스에서 펜·손가락으로 그을 때 화면이 끌려가지 않는다(`touch-action: none`)
- [ ] 102자를 S펜으로 써서 판정 허용 범위를 확인한다. ‘어려움’ 난이도도 시험(명세 14-2 12번)
- [ ] 쓰기 칸이 5:3 화면에서 잘리지 않는다
