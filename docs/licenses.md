# 꼬마학교 라이선스·출처

> 06 문서 6장(콘텐츠 권리)에 따라 앱에 들어가는 글꼴·음원·그림·오픈소스의 출처와 라이선스를 기록한다.
> 앱 안에서는 부모 모드 > 앱 정보(`src/screens/parent/about.ts`, 문구는 `src/core/strings.ts`)에 같은 내용을 보여 준다.

## 5. 개인정보

앱은 어떤 정보도 수집·전송하지 않는다. 학습 기록은 기기 안(`localStorage`)에만 저장된다. 네트워크 통신은 PWA의 자기 호스트 업데이트 확인뿐이며 사용자 데이터를 보내지 않는다 (06 문서 4장 6, 5장).
