# 후보 과목 (기획 초안)

> 아직 착수하지 않은 과목의 초안이다. 착수할 때 과목 하나를 `subjects/<id>.md`로 옮겨 상세 기획(활동·별 기준·설정·음원·테스트·미결정)을 채우고, 이 문서에서는 지운다.
> 순서는 `01_기획_개요.md`의 과목 목록을 따르되 아이 반응을 보며 바꿔도 된다.

## 3단계 후보

### 구슬 세기 (Bead Counting) · `counting`

**목표**: 1~20 수 세기, 수량과 숫자 연결, 10을 한 묶음으로 보기

**활동**
1. **세어 보기**: 사과·자동차 등 사물을 하나씩 터치하면 “하나, 둘, 셋…” 음성 → 마지막에 “모두 몇 개?” 숫자 카드 3개 중 고르기
2. **10칸 판 채우기**: 10칸 판(텐프레임)에 구슬을 넣어 “7 만들기”, “10이 되려면 몇 개 더?”
3. **숫자 짝짓기**: 숫자 카드와 같은 개수의 그림 카드 짝 맞추기

**단계 조절**: 1~5 → 1~10 → 11~20, 3번 연속 정답 시 범위 확장

**부모 설정**: 최대 수(5/10/20), 활동 종류 켜기/끄기

### 그림 교실 1차 (Drawing Class) · `drawing`

**목표**: 선 조절력(운필력) — 한글 획 쓰기의 바탕

**활동**
1. **선 따라 그리기**: 점선을 따라 직선 → 지그재그 → 물결 → 동그라미 → 나선. ‘강아지가 집까지 가는 길’처럼 이야기 붙이기
2. **점 잇기**: 1~10(이후 1~20) 숫자 점을 순서대로 이으면 그림 완성 → 수 순서 복습
3. **오늘의 그림 + 갤러리**: 음성 주제(“비 오는 날 우산 쓴 나”) 또는 자유 그리기 → 날짜별 갤러리 저장, 채점 없음

**펜 입력**: 갤럭시 탭 S펜의 압력(`pressure`)으로 선 굵기를 바꾸는 붓을 하나 둘 수 있다(아이패드는 압력이 없으므로 일정한 굵기로 동작)

**판정**: 선 따라·점 잇기만 판정 — `shared/judge`의 리샘플링·평균 거리 계산 재사용(정확도는 칭찬 연출 단계로만 표현)

**별 기준(제안)**: 선 따라 그리기 한 세트(5개 선) 완료 = 별 1개, 점 잇기 그림 1개 완성 = 별 1개, 자유 그림을 갤러리에 걸기 = 별 1개

**저장**: 그림은 IndexedDB에 JPEG + 썸네일 (껍데기에 IndexedDB 저장 유틸 추가 필요)

## 4단계

### 듣고 쓰기 (Listen & Write) · `dictation`

**목표**: 따라 쓰기에서 혼자 쓰기로 넘어가기

**활동**
1. 그림 + 음성으로 단어 제시(“나무”, “우유”, “사과”)
2. 칸에 직접 쓰기 — 가이드가 단계별로 연해짐: 진한 따라쓰기 → 점선 → 첫 글자만 힌트 → 빈칸
3. 다 쓰면 정답 글자를 겹쳐 보여주고, 획순이 틀린 획만 다시 쓰기

**구현 메모**: `writing`의 글자 데이터(102자)와 `shared/judge`를 그대로 쓰고, 가이드 층만 단계별로 흐리게 그린다. 102자에 없는 글자(받침 글자 등)는 글자 편집기로 추가

**단어 목록**: 받침 없는 2글자 → 받침 있는 2글자 → 3글자 (단어 데이터 JSON으로 관리, 부모가 추가 가능)

### 글자 블록 (Letter Blocks) · `letter-blocks`

**목표**: 초성+중성+종성 조합 원리, 받침 글자 읽기

**활동**
1. **글자 만들기**: ㄱ + ㅏ 블록을 끌어 놓으면 ‘가’가 되며 소리 재생 → 받침 ㅁ을 붙이면 ‘감’
2. **단어 완성**: ‘감’ + ‘자’ → ‘감자’ 그림 등장
3. **소리 듣고 고르기**: “곰”을 듣고 ‘공/곰/곤’ 중 고르기(받침 구별)

## 5단계

### 그림 셈놀이 (Picture Math) · `picture-math`

**목표**: 10 이내 더하기·빼기의 의미 이해

**활동**
1. 상황 그림 + 음성: “참새 3마리가 있었는데 2마리가 더 날아왔어요. 모두 몇 마리?”
2. 그림을 터치해 세어 보거나, 정답 숫자를 손가락으로 직접 쓰기(`writing`의 숫자 글자 데이터 + `shared/judge`로 0~9 판정)
3. 익숙해지면 그림 대신 구슬, 마지막엔 식(3 + 2 = ?) 함께 보여주기

**단계 조절**: 더하기 5 이내 → 10 이내 → 빼기 → 섞기

### 모양 퍼즐 (Shape Puzzle) · `shape-puzzle`

**목표**: 규칙 찾기, 도형 인식, 공간 감각

**활동**
1. **다음은 뭘까?**: ‘빨파빨파?’, ‘○△○△?’, ‘큰작큰작?’ 패턴의 다음 칸 고르기
2. **모양 맞추기**: 그림자 실루엣에 도형 조각 끌어 넣기(간단한 칠교놀이)
3. **같은 모양 찾기**: 돌아간 도형 중 같은 것 고르기

### 그림 교실 2차 (Drawing Class) · `drawing` 확장

**활동**
1. **도형으로 그리기**: 동그라미 하나 → 세모 귀 두 개 → 눈·코 → 고양이. 단계별 흐린 가이드, 익숙해지면 그림 카드만 보고 그리기
2. **나머지 반쪽 그리기**: 나비·얼굴·집의 반쪽을 보고 완성. 처음엔 ‘거울 붓’(자동 대칭)으로 놀이
3. **색칠 놀이**: 터치 한 번에 칠하는 페인트 통 + 선 밖으로 안 나가는 크레파스 붓

**성장 기록**: 매달 첫 주 ‘우리 가족 그리기’ 고정 주제 → 부모 모드에서 월별 비교

## 6단계

### 시계와 하루 (My Day Clock) · `my-day`

**목표**: 정시·30분 시계 읽기, 하루 순서, 요일 개념

**활동**
1. **시계 맞추기**: “3시로 맞춰 볼까?” → 바늘을 돌려 맞추기(처음엔 긴바늘 고정, 짧은바늘만)
2. **하루 순서**: ‘일어나기 → 세수 → 아침 먹기 → 유치원 가기’ 카드를 순서대로 배열
3. **오늘은 무슨 요일?**: 요일 노래 + 어제·오늘·내일 고르기

**부모 설정**: 우리 아이 하루 일과 카드 편집(사진 대신 그림 아이콘 선택)

## 여유가 있을 때

### 첫소리 탐정 (First Sound Detective) · `first-sound`

- “ㄱ으로 시작하는 걸 모두 찾아요!” → 그림 6장 중 고양이·기차·가방 고르기
- 받아쓰기의 바탕이 되는 음운 인식 훈련. 그림+음성 데이터만 있으면 되어 개발이 가장 쉽다

### 엄마아빠 동화책 (Voice Storybook) · `storybook`

- 한 페이지에 그림 + 문장 한 줄, 낱말을 누르면 부모 목소리로 읽어 줌
- 부모 모드에서 녹음 대신, PC에서 녹음한 mp3를 저장소에 넣어 배포하는 방식(iOS 12 웹앱의 마이크 녹음 제약 회피)
- 읽기 유창성, 잠자기 전 루틴용
