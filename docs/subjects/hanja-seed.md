# 한자씨앗 · `hanja-seed` — 공개용·가족용

> 옛 09 문서 12장(12.1~12.3, 12.5)을 옮긴 과목 명세다. 에디션 구분 구현 기준(옛 12.4)은 `06_배포_스토어_정책.md` 12장.
> 상태: **기획 중** — 아래 미결정 항목을 정한 뒤 착수. 한자똑똑(1) 이후.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 한자똑똑(1~3)의 학습 경험을 공개용 앱에서 하나의 과목으로 제공 |
| 과목 이름 | **한자씨앗 (확정).** 표기는 붙여 쓴다. 코드 식별자 예: `hanja-seed`. "한자똑똑"·"똑똑"을 연상시키는 문구 금지 |
| 에디션 | **공개용과 가족용 모두** (2026-10-22 결정). 가족용에서는 한자똑똑(1~3)과 별개 과목으로 허브에 함께 보인다 |
| 한자똑똑과의 관계 | 한자똑똑(1~3) = 우리 아이가 배운 한자만 복습(가족용 전용). 한자씨앗 = 그 한자를 모두 종합한 과목(공개). 기존에 기획한 ‘한자똑똑 모아 복습(`hanja-review`)’은 한자씨앗으로 대체한다 |
| 대상 | 만 4~5세 |

## 2. 한자 구성

- 한자똑똑(1~3)에서 다루는 한자를 **하나의 한자 목록**으로 합친다 (중복 제거).
- 목록은 **묶음** 단위로 나눈다. 묶음 이름은 중립적으로 짓는다 (예: "1묶음", 또는 "숫자", "자연", "사람"처럼 주제). 원래 교재 권 번호나 교재 이름을 드러내지 않는다.
- 공개용 콘텐츠는 **자체 제작**만 쓴다(그림은 한자똑똑과 공용으로 직접 그린 SVG를 쓴다 — `src/shared/hanja/pictures/`, 2026-10-22 결정): 그림, 예시 단어·문장, 음원 대사, 문항 구성. 교재의 예문·그림·문항·순서를 그대로 옮기지 않는다. (한자 글자와 훈음 자체는 공통 지식이라 사용 가능)
- **훈음 표기는 한자똑똑과 같은 현행 표기(학습지 포스터 표기)를 유지한다** (2026-10-22 결정). 예: 金 금 금, 土 흙 토, 弟 동생 제, 男 남자 남, 山 산 산. 일반 사전 표기(쇠 금, 아우 제, 사내 남, 뫼 산 등)로 바꾸지 않는다. 한자똑똑 이후에 추가되는 한자도 해당 학습지 표기를 따른다
- 한자 데이터는 과목 폴더 안의 데이터 파일 하나로 관리한다 (예: `hanja.json` — 글자, 훈, 음, 묶음, 순서, 음원 대사 ID).

## 3. 부모의 공개 범위 선택

| 항목 | 기준 |
|---|---|
| 위치 | 부모 모드 > 과목 설정 > 한자씨앗 > 학습할 한자 |
| 선택 단위 | 묶음 단위 켜기/끄기 + 묶음 안에서 글자 개별 켜기/끄기. "전체 켜기/전체 끄기" 제공 |
| 기본값 | 첫 묶음만 켜짐 |
| 아이 화면 | 켜진 한자만 학습·문제·보상에 등장 |
| 끈 한자의 기록 | 지우지 않는다. 다시 켜면 이전 진행이 그대로 보인다 |
| 최소 개수 | 켜진 한자가 너무 적어 문제를 만들 수 없으면 (예: 4지선다에 4자 미만) 부모 화면에서 안내하고 저장을 막는다 |
| 저장 | Store(`core/storage.ts`) 경유, 기기 내 저장 |
| entitlements와의 관계 | entitlements = 과목·묶음을 쓸 **권한**(향후 유료화 대비), 부모 선택 = 권한 범위 안에서의 **학습 범위**. 두 개를 섞지 않는다 |

## 4. 파일 배치·에디션

- 과목 폴더: `src/apps/hanja-seed/`(데이터 `hanja.json`, 대사 `voices.json`), 음원 `public/apps/hanja-seed/voice/`
- 엔진과 그림은 한자똑똑과 공용(`src/shared/hanja/`). 한자똑똑 폴더(`src/apps/hanja/`, `public/apps/hanja/`)의 파일을 import하거나 참조하지 않는다
- 등록 정보 `editions: ['family','public']` — 에디션 구분 장치는 B 단계에 구현 (06 문서 12장)

## 참고: 기존 ‘한자똑똑 모아 복습’ 기획 (한자씨앗으로 대체)

아래는 기존 기획 기록이다. 한자씨앗 활동 구성을 정할 때 참고한다.

- 각 세트에서 ‘배운 한자’로 고른 한자를 모두 모아 섞어서 문제를 낸다
- 내 한자판은 세트별 페이지(옆으로 넘기기)로 보여 주고, 전체 익힘 정도(예: 48자 중 35자 별 3개)를 표시
- 세트끼리 헷갈리는 짝(예: (1)의 手와 다른 세트의 ‘수’ 한자)을 일부러 함께 낸다
- 부모 설정: 넣을 세트 선택, 익힘 단계 낮은 한자 위주 / 골고루
