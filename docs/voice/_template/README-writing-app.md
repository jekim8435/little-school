# 아이 목소리 음원 넣기

앱이 읽어 주는 말을 AI 음성 서비스로 만든 녹음 파일로 바꾸는 방법입니다.
녹음 파일이 있는 대사는 그 파일을 틀고, 없는 대사는 지금처럼 기기 음성으로 읽습니다.
그래서 **일부만 먼저 넣어도 됩니다** (예: 칭찬 5개부터).

## 1. 만들 대사

[대사목록.csv](대사목록.csv)를 엑셀이나 구글 시트로 엽니다. 대사는 모두 96개입니다.

| 칸 | 뜻 |
|---|---|
| 파일 이름 | 저장할 파일 이름. **이 이름 그대로** 저장해야 앱이 찾습니다 |
| 읽을 문장 | AI 음성 서비스에 넣을 문장 |
| 언어 | 한국어 / 영어 |
| 쓰이는 곳 | 앱에서 이 말이 나오는 때 |

## 2. AI 음성 서비스에서 만들기

- **목소리**: 7~10살쯤 되는 아이 목소리를 고릅니다. 칭찬(`praise-*`)과 끝냈을 때(`ending-*`)는 신나고 들뜬 말투, 틀렸을 때(`retry-*`, `free-fail`)는 다정한 말투가 어울립니다.
- **영어 26개**(`letter-a` ~ `letter-z`): 영어 목소리로 알파벳 이름을 읽게 합니다. 한국어 목소리로 만들면 "에이, 비"처럼 들립니다.
- **"~" 표시**: "우와~"처럼 늘여 말하라는 뜻입니다. 서비스가 "~"를 이상하게 읽으면 "우와아"처럼 바꿔 넣어도 됩니다 (파일 이름만 그대로면 됩니다).
- **앞뒤 빈 소리**: 말 앞뒤의 무음이 길면 글자를 쓴 뒤 소리가 늦게 나옵니다. 0.2초 안쪽으로 잘라 주세요.
- **파일 형식**: **mp3**(또는 m4a). 한 파일에 100KB 이하면 충분합니다 (모노, 64kbps 정도).
- **사용 조건**: 서비스마다 만든 음성을 앱에 넣어 배포해도 되는지(라이선스) 약관을 확인하세요.

## 3. 앱에 넣기

1. 만든 파일을 `voice/clips/` 폴더에 넣습니다. 예: `voice/clips/praise-1.mp3`
2. 잘 들어갔는지 확인합니다. 몇 개가 들어갔고 몇 개가 남았는지, 이름이 틀린 파일이 있는지 알려 줍니다.

   ```bash
   npm run voice:lines
   ```

3. `main` 브랜치에 push하면 자동으로 배포되고, 아이패드에서 앱을 열면 새 버전으로 바뀝니다. 녹음 파일도 기기에 저장되어 오프라인에서도 나옵니다.

## 문장을 바꿀 때

칭찬 같은 문장은 `src/data/messages.ts`에서 고칩니다. 고친 뒤에는 꼭 다음을 합니다.

1. `npm run voice:lines`로 대사 목록을 다시 만듭니다 (안 하면 테스트가 실패합니다).
2. **바뀐 문장의 녹음 파일은 다시 만들어 덮어씁니다.** 파일 이름은 그대로라서, 그냥 두면 예전 문장이 나옵니다.

## Typecast로 한 번에 만들기

[Typecast](https://typecast.ai) API로 대사 목록 전체를 자동으로 만들 수 있습니다 (`scripts/voice-make.mjs`).
ffmpeg가 있으면 앞뒤 무음을 자르고 mp3 모노 64kbps로 줄여 줍니다 (`winget install ffmpeg`).

1. [API 콘솔](https://studio.typecast.ai/developers/api)에서 키를 만들고 환경변수로 넣습니다. 키는 저장소에 넣지 않습니다.

   ```powershell
   $env:TYPECAST_API_KEY="발급받은_키"
   ```

2. 아이 목소리를 찾아 `voice/typecast.json`의 `koVoice`(한국어), `enVoice`(영어)에 ID를 넣습니다. 목소리마다 쓸 수 있는 감정이 다르니 `happy`가 있는 목소리를 고릅니다.

   ```bash
   npm run voice:make -- --list-voices --age child
   ```

3. 만듭니다. 이미 있는 파일은 건너뜁니다.

   ```bash
   npm run voice:make -- --dry-run              # 보내기 전에 문장·말투만 확인
   npm run voice:make -- --only praise-1        # 하나만 먼저 들어 보기
   npm run voice:make                           # 전부 만들기
   npm run voice:make -- --only praise --force  # 고친 문장만 다시 만들어 덮어쓰기
   npm run voice:lines                          # 확인
   ```

`voice/typecast.json` 설정:

| 칸 | 뜻 |
|---|---|
| `styles` | 파일 이름 앞부분별 감정(`normal`, `happy`, `sad`, `tonedown` 등)과 세기(0~2) |
| `replace` | 보내기 전에 바꿀 글자. 예: `{ "~": "" }` |
| `tempo` / `pitch` | 빠르기(0.5~2.0) / 높낮이(-12~12) |
| `lufs` | 소리 크기 맞추기 (기본 -16) |
