## 4. 플랫폼 이식성 원칙 (Claude Code 필수 준수)

> 프로젝트는 TypeScript다. 이 문서에 나오는 새 파일은 모두 `.ts`로 만든다.

1. **상대 경로**: 모든 리소스 경로는 `./` 기준. 빌드 기준 경로(vite `base`)도 `./`로 하고, manifest의 `start_url`·`scope`도 상대 경로로 둔다. 도메인·배포 경로(`/little-school/`)에 의존하지 않는다. (기존 명세 11-3의 `/little-school/` 절대 경로 결정은 이 항목으로 대체)
2. **플랫폼 어댑터 단일화**: 플랫폼별 분기는 `src/platform/` 한 곳에서만 처리한다.
   - `platform.isNativeApp()`, `platform.isPWA()`
   - Service Worker 등록, 설치 안내, 화면 꺼짐 방지, 방향 고정 등은 어댑터 내부 구현
   - 서비스 워커 등록·업데이트 확인(기존 `src/pwa.ts`), standalone 판별, 저장소 유지 요청(`navigator.storage`), UserAgent 기반 기기 구분도 어댑터로 옮긴다
   - 과목·허브·부모 모드 코드에서 `navigator.standalone`, `navigator.serviceWorker`, `navigator.storage`, `navigator.userAgent`, `window.Capacitor` 직접 참조 금지
3. **저장소 래퍼**: 학습 기록·보상판·설정·PIN은 반드시 `src/core/storage.ts`의 Store를 통해서만 읽고 쓴다. localStorage 직접 접근 금지 (저장 공간 크기 계산 같은 진단 기능도 Store에 함수로 둔다).
   - 저장 키는 **현행 `little-school:v1` 단일 키를 유지**한다. 키 이름 변경은 기록 유실 위험에 비해 얻는 것이 없어 하지 않는다.
   - 저장 데이터에 `schemaVersion`을 포함한다 (현행 유지). 구조가 바뀌면 schemaVersion을 올리고 Store 안에서 이전한다.
4. **문구 집중**: 화면에 보이는 문구는 `src/core/strings.ts`에서 가져온다.
   - **적용 방식: 점진 이전.** 3단계부터 새로 만드는 화면·과목은 처음부터 strings.ts를 쓴다. 기존 화면은 그 화면을 고칠 때 함께 옮긴다. 일괄 이전 작업은 하지 않는다.
   - 아이에게 들려주는 문장(음원 대사)은 strings.ts가 아니라 voices.json에서 관리한다 (현행 유지).
5. **외부 리소스 금지**: CDN 폰트·외부 이미지·외부 스크립트 사용 금지. 모든 파일은 로컬 번들.
6. **네트워크 호출 금지**: 런타임에 어떤 서버와도 통신하지 않는다 (분석·로그·광고 SDK 포함).
   - **예외: PWA의 자기 호스트 업데이트 확인**(서비스 워커가 앱이 배포된 호스트에 새 버전을 묻는 것)은 허용한다. 사용자 데이터를 보내지 않으므로 데이터 수집에 해당하지 않는다.
   - Capacitor 앱에서는 업데이트를 스토어가 담당하므로, 어댑터에서 이 확인을 끈다.
7. **오디오는 사용자 터치 이후 시작**: 첫 소리는 반드시 터치 이벤트에서 재생 시작.
8. **전체 프리캐시(PWA)**: 설치 시 모든 과목의 리소스(음원 포함)를 미리 캐시한다. 기준은 "오프라인에서 필요한 파일이 하나도 빠짐없이 기기에 있는가"다.
   - 과목 코드를 열 때 불러오는 방식(동적 import)은 허용한다. 파일 자체는 설치 때 모두 받아 두기 때문이다 (현행 `check-precache.mjs` 검사 유지).
   - 금지하는 것은 "필요할 때 네트워크에서 처음 받아오는" 방식이다.

## 5. 아동 대상 앱 정책 준수 설계 (Google Play 가족 정책 대비)

| 항목 | 설계 기준 |
|---|---|
| 타깃 연령 | 만 5세 이하 |
| 개인정보 수집 | **수집 없음.** 이름·사진·음성 녹음·위치·기기 ID 등 일체 수집·전송하지 않음 |
| 광고/결제 | 현재 없음 (1장 수익화 결정 시 재검토) |
| 외부 링크 | 아이 화면에는 없음. 필요한 링크는 부모 게이트 뒤에만 둔다 |
| 부모 게이트 | **현행 방식 유지 (확정).** 기본은 곱셈 문제(두 자리 × 한 자리, 매번 무작위), 4자리 PIN은 부모가 공통 설정에서 켜는 선택 사항. 기본 PIN 값은 없다. 3회 오답 시 1분 잠금(현행). PIN을 켠 상태에서 분실했을 때 다시 들어올 수 있는 경로가 있어야 한다 (예: PIN 화면의 "PIN을 잊었어요" → 곱셈 문제 통과 시 PIN 해제). 외부 링크(개인정보처리방침 등)는 부모 모드 안에만 둔다. PIN은 기기 내 저장만, 전송 없음 |
| 권한 | 인터넷 외 위험 권한 요청 없음. 마이크·카메라 기능은 별도 기획 후 결정 |
| 데이터 보안 양식 | "수집·공유하는 데이터 없음"으로 제출할 수 있게 유지 |

> 새 기능이 위 표 중 하나라도 바꾸게 되면, 개발 전에 기획 문서에 먼저 반영하고 결정한다.
