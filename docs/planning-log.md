## 2026-10-21

- 1단계 1~2번 구현 중 정한 것 — 명세 2-2, 11-3, 14-1
  - `base`는 `/little-school/`로 통일(명세 11-3). Capacitor용 빌드(`VITE_NATIVE=1`)만 상대 경로 `./`. 2단계에서 과목도 이 값을 따른다
  - flex/grid `gap`은 CSS에서 전면 금지(명세 2-2 그대로). 한글쓰기 앱의 `no-flexgap` 대체 규칙 방식과 `markFlexGapSupport()`는 가져오지 않았다 → 2단계 이식 때 쓰기 앱 CSS의 `gap`을 자식 `margin`으로 바꿔야 한다
  - 호환성 검사 2종에 명세 2-2 중 빠져 있던 항목 추가: `gap`, `:is()`/`:where()`, `dvh` 등 새 뷰포트 단위, 정규식 lookbehind, 최상위 `await`. 소스 검사는 `src/` 아래 모든 CSS 파일을 본다
  - `public/sw-bridge.js`(한글쓰기 앱의 옛 버전 → 배너 버전 전환용)는 꼬마학교에 옛 버전이 없어 가져오지 않음
  - `router.ts`는 쓰기 앱 전용 화면 타입을 떼고 일반화만 했다. 해시 라우팅 확장은 3번에서
  - 2번 배포 확인용 빈 화면(`src/screens/blank.ts`)에 화면 크기·실행 방식·입력 종류·빌드 시각을 표시. 시작 화면이 생기면 지운다

- 한글쓰기 앱 소스를 `legacy/writing-practice/`에 사본으로 배치(원본은 계속 유지), Typecast 도구·설정·대사목록을 `docs/voice/_template/`에 보관. 2단계 이식 지도를 실제 파일 경로와 설정 key(`freeHint`, `autoDemo` 등)로 갱신, 음원 도구는 기존 `voice-make.mjs` 기반으로 — 명세 14-1, 14-4, 15-3

- 대상 기기에 Galaxy Tab S6 Lite(Chrome, S펜) 추가. 펜 입력(호버 무시, 손바닥 무시, ‘펜으로만 쓰기’), 5:3 화면 대응, 기기별 화면 고정·설치 안내, 기기 정보 화면 — 명세 2-5, 8-6, 8-7, 10장, 11장, 13장
- 앱 전체 가로 모드 고정. 아이 화면 세로 스크롤 금지, 세로 방향 안내 화면 — 명세 2-4, 10장 / 과목 목록 공통 메모
- 한자똑똑(1) 추가(학습지 포스터 32자, 음뜻은 포스터 표기). 배운 한자는 한 자씩 선택, 활동을 골라 한자 10개를 끝내면 별 1개, 출제 주머니로 고르게 출제, 내 한자판 8열×4줄에 32자 전체 표시 — 과목 목록 ‘한자똑똑’
- 음원 관리: 대사 ID(`voices.json`) + `ctx.audio.say`, 단계·과목 마무리 때 음원 목록 정리 후 Typecast 제작 — 명세 15장
- 과목별 설정 페이지(`settingsSchema` 자동 생성, `multi` 형식 포함)와 공통 설정(효과음·음성) 분리. 한글쓰기 앱 설정 6개 이식 방법 — 명세 8-5, 8-6, 14-4
- 보상 규칙: 과목별 교환 비율, 과목당 하루 스티커 1장, 판이 차도 계속 쌓임, 보상 지급 시 내용 입력 — 명세 6장
