## 2026-10-21

- 아이패드 상태 표시줄을 `black-translucent` → `default`(흰 띠 + 검은 시계)로 변경. 아이패드에서 흰 시계가 크림색 배경에 묻혀 안 보였음(부모 선택). 앱 화면은 상태 표시줄 아래 1024×748이 되므로 높이 기준 단위를 `--u` = 화면 높이 ÷ **748**로 바꿔 아이패드에서 1px이 되게 함. 위쪽 20px을 비우던 `--status`·`ios-standalone` 처리는 삭제 — 명세 2-5, 10장, 11-1

- 1단계 3번(storage·라우터·공통 스타일) 구현 중 정한 것 — 명세 5장, 9장, 10장
  - 데이터 모델에 빠져 있던 필드 추가: `settings.penOnly`(8-6 펜으로만 쓰기), `device.penSeen`(펜 감지 기기에서만 표시), `lastBackupAt`(11-4 마지막 백업). 하루 학습 시간 ‘제한 없음’은 `dailyMinutes: null`
  - 저장 데이터가 깨져 있으면 원본을 `little-school:v1:broken`에 남기고 새로 시작. 앱이 가려질 때는 300ms를 기다리지 않고 바로 저장
  - 부모 모드 주소를 정함: `#/parent`가 부모 홈, 나머지는 `#/parent/<페이지>`, 과목별 설정은 `#/parent/subjects/<id>`. 보상 지급·보상 기록·기기 정보 주소도 추가. 모르는 주소는 시작 화면으로
  - 높이 기준 단위 `--u` = 화면 높이 ÷ 768(px). 세로일 때는 짧은 변 기준. iOS 홈 화면 앱(`navigator.standalone`)이면 위쪽 상태 표시줄 20px을 비운다(`--status`) → 같은 날 상태 표시줄 변경으로 ÷ 748, `--status` 삭제(위 항목)
  - 세로 방향 안내 화면(2-4)을 3번 공통 컴포넌트로 먼저 만듦(그림·문구만). 음성은 4번, 과목 pause·시간 멈춤은 5·7번에서 연결
  - 확인용 빈 화면에 ‘연 횟수’(저장 유지 확인용, `apps._check`)·확인창 시험 버튼 추가. 4번 시작 화면을 만들 때 함께 지운다

- 갤럭시 탭 S6 Lite 실기기 확인을 보류하고 아이패드 에어1 기준으로 먼저 진행. 갤럭시 탭 대응 코드는 명세대로 넣되, 확인할 항목은 `docs/galaxy-tab-checklist.md`에 단계마다 쌓아 두었다가 기기가 준비되면 한 번에 확인·일괄 수정 — 명세 13장, CLAUDE.md 규칙 1

- 1단계 1~2번 구현 중 정한 것 — 명세 2-2, 11-3, 14-1
  - `base`는 `/little-school/`로 통일(명세 11-3). Capacitor용 빌드(`VITE_NATIVE=1`)만 상대 경로 `./`. 2단계에서 과목도 이 값을 따른다
  - flex/grid `gap`은 CSS에서 전면 금지(명세 2-2 그대로). 한글쓰기 앱의 `no-flexgap` 대체 규칙 방식과 `markFlexGapSupport()`는 가져오지 않았다 → 2단계 이식 때 쓰기 앱 CSS의 `gap`을 자식 `margin`으로 바꿔야 한다
  - 호환성 검사 2종에 명세 2-2 중 빠져 있던 항목 추가: `gap`, `:is()`/`:where()`, `dvh` 등 새 뷰포트 단위, 정규식 lookbehind, 최상위 `await`. 소스 검사는 `src/` 아래 모든 CSS 파일을 본다
  - `public/sw-bridge.js`(한글쓰기 앱의 옛 버전 → 배너 버전 전환용)는 꼬마학교에 옛 버전이 없어 가져오지 않음
  - `router.ts`는 쓰기 앱 전용 화면 타입을 떼고 일반화만 했다. 해시 라우팅 확장은 3번에서
  - 2번 배포 확인용 빈 화면(`src/screens/blank.ts`)에 화면 크기·실행 방식·입력 종류·빌드 시각을 표시. 시작 화면이 생기면 지운다
