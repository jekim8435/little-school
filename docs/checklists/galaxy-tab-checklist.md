## 1. 설치·실행 (1단계 2번)

- [ ] Chrome 메뉴 > **앱 설치**(또는 홈 화면에 추가)로 아이콘이 생긴다. 이름 ‘꼬마학교’, 집 모양 아이콘이 잘리지 않는다(마스커블)
- [ ] 아이콘으로 실행하면 주소창 없이 열리고, **위쪽에 상태 표시줄(시계)이 보인다** — 기기 정보의 실행 방식 `홈 화면 앱 (standalone)`. (2026-10-22: 전체 화면이라 시계가 안 보여 standalone으로 바꿈. 설치된 앱에 반영이 안 되면 홈 화면 아이콘을 지우고 다시 설치)
- [ ] 기기를 세로로 돌려도 **가로로 고정**된다
- [x] 입력 방식 `Pointer Events`. 마지막 입력이 손가락 `touch`, S펜 `pen`으로 바뀐다 (2026-10-22 pen 확인)
- [ ] ‘소리 확인’에서 팡파레가 난다
- [ ] 당겨서 새로고침이 일어나지 않는다
- [ ] 길게 눌러도 메뉴(복사·검색 등)가 나오지 않는다. 글자가 선택되지 않는다
- [ ] 두 손가락 확대·두 번 눌러 확대가 되지 않는다
- [ ] 한 번 연 뒤 비행기 모드에서 아이콘으로 실행해도 열린다 (2026-10-22 기기 정보 ‘오프라인: 준비됨’)
- [ ] 빌드 시각이 최신 배포와 같다(새 버전이 들어왔는지)

## 1-2. 공통 스타일·저장 (1단계 3번)

- [ ] 확인용 화면의 `--u` 값이 화면 높이 ÷ 748과 같다(예: 높이 800이면 약 1.07px). 글자·버튼이 넘치거나 잘리지 않는다
- [ ] 위쪽 상태 표시줄과 앱 화면이 겹치지 않는다
- [ ] 앱을 완전히 닫았다 다시 열면 ‘연 횟수’가 1씩 는다(저장 유지)
- [ ] ‘확인창’ 버튼: 확인창이 가운데 뜨고, 확인·취소·바깥 누르기 모두 닫히며 위쪽에 토스트가 뜬다
- [ ] ‘다른 화면’ → ‘준비 중’ 화면 → ‘처음으로’로 돌아온다. 뒤로 가기 버튼(안드로이드)으로도 앞 화면으로 돌아간다
- [ ] 브라우저 탭(설치 전)에서 기기를 세로로 돌리면 ‘옆으로 돌려 주세요’ 안내가 뜨고, 가로로 돌리면 사라진다

## 1-3. 시작 화면·소리 (1단계 4번)

- [ ] 시작 화면(하늘색, 집 그림, ‘꼬마학교’, ‘시작!’)이 넘치지 않고 가운데에 보인다
- [ ] ‘시작!’을 누르면 ‘톡’ 소리와 함께 인사 음성이 나오고 ‘준비 중(#/hub)’으로 넘어간다
- [ ] ‘기기 정보’: 화면 크기·배율·`--u`, 입력 방식 `Pointer Events`, 마지막 입력(손가락 `touch`, S펜 `pen`)이 맞다
- [x] S펜으로 화면을 누르면 ‘펜 압력’에 값이 나오고 ‘펜 사용 기기’가 ‘예’로 바뀐다 (2026-10-22: 압력 0.08, 예)
- [ ] ‘사용 중인 음성’에 한국어 음성이 나온다(처음 열 때 목록이 늦게 채워져도, 다시 들어가면 나오는지) — 2026-10-22: ‘기본 음성’으로 표시됨(제작 음원은 mp3라 영향 적음, 다시 들어가도 같으면 고칠 것)
- [ ] 소리 시험: 효과음 5개(톡·정답·오답·별·팡파레)와 음성 읽기가 모두 들린다
- [ ] 기기 정보 화면이 세로로 스크롤된다
- [ ] (설치 전 브라우저 탭) 세로로 돌리면 ‘옆으로 돌려 주세요’ 음성이 나온다

## 1-4. 허브·과목 화면·샘플 과목 (1단계 5번)

- [ ] 허브: 위쪽 ‘오늘 스티커’와 스티커판 버튼(0/10)이 넘치지 않는다. 샘플 타일이 가운데에 보이고 글자가 잘리지 않는다(5:3 넓은 화면)
- [ ] 샘플 타일을 손가락·S펜으로 누르면 ‘톡’ + ‘샘플’ 음성 후 과목 화면으로 들어간다
- [ ] 과목 화면 상단 바(집·샘플·★ n/3)가 한 줄에 보인다
- [ ] 동그라미 5개를 손가락·S펜으로 누르면 하나씩 흐려지고, 다 누르면 별 소리·초록 동그라미 연출 후 2초 뒤 허브로 돌아간다. 허브 배지가 ★ 1/3 → 2/3으로 는다
- [ ] S펜을 띄운 상태(호버)로 동그라미 위를 지나가도 눌리지 않는다
- [ ] 집 버튼: 한 번 누르면 말풍선 + 음성, 3초 안에 한 번 더 누르면 허브로
- [ ] 허브 오른쪽 위 모서리를 3초 누르면 ‘준비 중(#/parent/gate)’ → ‘기기 정보’로 갈 수 있다. 짧게 누르면 아무 일도 없다
- [ ] 안드로이드 뒤로 가기 버튼으로 과목 화면에서 허브로 돌아가도 과목이 정상 정리된다(다시 들어가도 동그라미가 새로 그려짐)

## 1-5. 별·스티커판·오늘 끝·부모 모드 (1단계 6~8번)

- [ ] 샘플을 3번 끝내면 별이 상단 바로 날아가고, 3번째에 스티커가 크게 나타나며 팡파레·음성. 그 뒤 샘플 배지가 ‘오늘 스티커 ✓’
- [ ] 스티커판(허브 오른쪽 위 📒) — 손가락·S펜으로 좌우로 밀어 판을 넘길 수 있고, 화살표·점도 맞다. 5:3 화면에서 판이 잘리지 않는다
- [ ] 보상 기록 카드가 가로로 넘어간다
- [ ] 공통 설정에서 하루 학습 시간을 10분으로 → 샘플을 10분 넘게 하면 한 판 뒤 ‘오늘 공부 끝’. 허브 타일이 잠긴 모양
- [ ] 부모 잠금: 허브·오늘 끝 화면 오른쪽 위 3초 → 곱셈 문제. 키패드를 손가락·S펜으로 누를 수 있다. 3번 틀리면 1분 잠금
- [ ] 부모 모드 각 화면이 세로로 스크롤되고 글자가 넘치지 않는다. 입력칸(보상 내용·복원·암호)에서 키보드가 뜨고 글자를 넣을 수 있다
- [ ] 백업 ‘복사하기’가 되고, ‘파일로 내려받기’로 JSON 파일이 받아진다(갤럭시 탭에서는 버튼이 보임)
- [ ] 아이패드에서 복사한 백업을 갤럭시 탭에 붙여 넣어 복원할 수 있다(기기 간 이동)
- [ ] 잠금 안내 화면이 ‘갤럭시 탭 (이 기기)’ 안내를 먼저 보여 준다. One UI 메뉴 이름이 실제와 맞는지 확인하고 다르면 적어 두기
- [ ] 펜으로 한 번 누른 뒤 공통 설정에 ‘펜으로만 사용하기’ 항목이 나타난다
- [ ] 부모 모드에서 5분 동안 아무것도 안 하면 허브로 돌아간다

## 2. 이후 단계에서 확인할 것 (명세 13장 중 갤럭시 탭 관련)

단계가 끝날 때마다 해당 항목을 여기로 옮겨 적고 확인한다.

- [ ] 두 기기 화면 비율이 달라도 넘침·잘림 없이 한 화면에 들어간다(5:3, 높이 기준 배치 — 명세 10장). 한글 글꼴(삼성/Noto) 폭 차이로 글자가 넘치지 않는다
- [ ] 부모 모드 > 기기 정보에 화면 크기·입력 종류·펜 압력이 맞게 나온다
- [ ] 첫 실행 때 `navigator.storage.persist()` 요청이 동작한다(기기 정보의 저장 공간 항목)
- [ ] 내장 음성: 목소리 목록이 늦게 채워져도 한국어 음성으로 읽는다(`voiceschanged`)
- [ ] 세로 방향 안내 화면이 (회전 고정 때문에) 뜨지 않거나, 떠도 정상 동작한다
- [ ] 부모 모드 > 잠금 안내·설치 안내가 **갤럭시 탭 안내를 먼저** 보여 준다. 앱 고정 메뉴 이름을 실기기 One UI 문구에 맞춘다(명세 8-7)
- [ ] ‘앱 고정’ 상태에서 모든 화면이 정상 동작한다
- [ ] 스티커판 좌우 슬라이드가 손가락·S펜 모두로 된다
- [ ] 과목을 10번 열고 닫아도 느려지지 않는다
- [ ] 백업 JSON 복사·파일 내려받기가 된다. 아이패드에서 만든 백업을 복원할 수 있다(기기 간 이동)
- [ ] 공통 설정의 ‘펜으로만 사용하기’ 항목이 S펜을 한 번 쓴 뒤에만 보인다

## 6. 구슬 세기 (3단계, 2026-10-22)

> PC에서 1024×748·1334×800 두 크기, 1·2·3단계 모두 넘침 0 확인함. 단계: 1단계 1~10 · 2단계 11~20 · 3단계 21~30
> 준비: 부모 모드 > 구슬 세기 설정에서 최대 수 기본 20(1·2단계). 21~30까지 보려면 30으로 바꾼다. 잘 맞히면 다음 판부터 단계가 오른다

- [ ] 허브에 구슬 세기 타일(산호색, 구슬 세 개), 누르면 “구슬 세기”를 읽는다. 활동 고르기 위 3개(세어 보기·10칸 판·10 만들기) · 아래 2개(숫자 짝짓기·숫자판)
- [ ] 세어 보기: 사물이 겹치지 않고, 가장 많은 개수(20개·30개)에서도 손가락·S펜으로 하나씩 잘 눌린다. 누르면 ① ② … 표시가 붙고 수를 읽는다
- [ ] 세어 보기: 이미 센 사물을 다시 누르면 수가 늘지 않고 ‘톡’ 소리만. 다 센 뒤에만 오른쪽 숫자 카드가 나오고 “모두 몇 개일까?”
- [ ] **빠르게 연달아 눌렀을 때 숫자 읽기가 밀리지 않는다**(앞 수를 끊고 새 수를 읽음). 음원을 넣은 뒤 다시 확인 — 처음 한 번씩 늦게 나오면 `audio.preload`를 추가한다
- [ ] 세어 보기 오답: 정답 카드가 초록, 표시가 1부터 차례로 깜빡이며 “모두 N 개!”
- [ ] 10칸 판(수만큼 놓기): 어느 빈 칸을 눌러도 윗줄 왼쪽부터 차고, 구슬을 누르면 마지막 하나가 빠진다. 판 수 = 단계(1·2·3개, 위아래)
- [ ] 10칸 판: 구슬 0개일 때 숫자 아래 ‘다 했어요’가 흐리고 안 눌린다. 1개 이상이면 켜진다
- [ ] 10칸 판 3단계: 판 3개(칸 76pt)가 잘리지 않고 누르기 쉽다. 판이 다 찰 때마다 반짝, 첫 판은 “열! 한 묶음이에요”
- [ ] 10 만들기: 구슬 1~9개가 놓인 판을 보고 숫자 카드를 고르면 파란 구슬(가운데 흰 점)이 하나씩 채워지며 이어 센다. 1단계에서도 나온다
- [ ] 숫자 짝짓기: 위 숫자 카드·아래 그림 카드. 2단계(4쌍)·3단계(3쌍) 그림 카드의 사물을 셀 수 있다(10개마다 테두리 묶음). 숫자 카드를 고르면 그 수를 읽는다. 모든 장이 끝나면 별
- [ ] 숫자판: 1~30이 10열 × 3줄, 누르면 큰 카드(10개마다 판 하나) + 수 읽기, 바깥을 누르면 닫힘
- [ ] 판 진행 중 ‘뒤로’는 두 번, 숫자판은 한 번에 나간다. 한 판 끝 → “모두 끝! 정말 잘했어요” + 별 1개
- [ ] 단계: 잘 맞히면 다음 판부터 수가 커지고(8문제 중 7개), 많이 틀리면 작아진다(6문제 중 3개) — 아이 반응 보고 기준 조정(과목 문서 14장)
- [ ] 한 판(세어 보기 6 / 10칸 판 6 / 10 만들기 6 / 짝짓기 12쌍)이 3~4분 정도인지, 21~30이 너무 길지 않은지
