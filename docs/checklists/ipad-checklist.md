## G. 2단계 또박또박 글씨 (명세 14-5)

- [ ] 허브 맨 앞에 ‘또박또박 글씨’ 타일, 샘플 타일은 숨겨짐. 누르면 ‘또박또박 글씨’ 음성
- [ ] 카테고리 7개(숫자·자음·모음·쌍자음·합성모음·영어 소문자·영어 대문자)가 한 화면에, 고르면 카테고리 이름 음성 → 따라 쓰기/혼자 쓰기 고르기
- [ ] 따라 쓰기: 손가락·정전식 펜으로 획을 그으면 판정(띵/뿅), 틀리면 토스트+음성, 3번 틀리면 그 획 애니메이션. 글자를 다 쓰면 칭찬 음성(기존 Typecast 음원)
- [ ] 따라 쓰기에서 한 획이라도 틀린 글자는 “끝까지 잘 썼어! 이 글자는 나중에 한 번 더” → 글자 띠에 주황 점, 회차 끝에 다시 나온다
- [ ] 혼자 쓰기: [확인]으로 판정, 틀리면 빨간 획 + [순서 보기] 애니메이션, [다시 쓰기]로 맞히면 클리어
- [ ] 쓰기 칸·글자 띠(영어 26자는 두 줄)·버튼이 스크롤 없이 한 화면에 들어간다. 획이 손가락을 잘 따라온다(끊김·지연 없음)
- [ ] 중간에 집으로 나갔다 다시 들어오면 회차가 이어진다(카드에 `9 / 14` 등)
- [ ] 카테고리 하나(쌍자음 5자가 빠름)를 다 클리어하면 엔딩 + 별, 3개면 스티커. 카테고리 카드에 🏆 클리어 횟수. 그 뒤로는 그날 별이 더 나오지 않는다
- [ ] 부모 모드 > 기록 > 자주 틀린 문제에 틀린 글자가 나온다
- [ ] 부모 모드 > 과목 관리 > 또박또박 글씨 설정: 판정 난이도·혼자 쓰기 힌트·획순 애니메이션 자동 재생·숫자 읽기 4개가 있고, 바꾸면 과목을 다시 열 때 반영(숫자 읽기 ‘하나, 둘, 셋’ → 숫자 글자 읽기가 바뀜)
- [ ] 공통 설정에서 효과음·음성 읽기를 끄면 또박또박 글씨에서도 꺼진다
- [ ] 아이 화면에 설정 버튼(톱니)이 없다
- [ ] 세로로 돌리면 안내가 뜨고 획순 애니메이션이 멈춘다

## I. 한자똑똑(1) (3단계 — 마지막에 확인)

> 2026-10-22 첫 배포 때 아이패드에서 32자 자형·내 한자판 칸 넘침은 이미 확인함(괜찮음). 나머지를 마지막에 본다.
> 준비: 앱을 완전히 닫았다 열어 화면 아래 빌드 시각이 최신인지 확인

- [ ] 허브에 한자똑똑 타일, 누르면 과목 이름을 읽는다
- [ ] 오늘 스티커를 받은 뒤 들어가면 ‘무엇을 할까요?’ 다음에 ‘오늘 스티커는 받았어요’가 끊기지 않고 이어서 나온다
- [ ] 활동 고르기 2줄 × 3. 배운 한자를 3자 이하로 하면 고르기·짝 맞추기가 잠기고 누르면 안내 음성
- [ ] 한자 카드: 누르면 뒤집히며(가로로 접히는 연출) 그림·훈음·음성, ‘다음’으로 넘김. ‘다음 한자 미리 보기’를 켜면 ‘곧 배워요’ 카드가 섞인다
- [ ] 한자 찾기(음뜻 보고 한자 고르기)·그림 고르기·음뜻 고르기: 보기 3개/4개 모두 글자·그림이 잘리지 않는다. 틀리면 정답 그림을 보여 주고, 판 끝에 ‘한 번 더!’ 문제
- [ ] 한 판(10개)을 끝내면 칭찬 화면 + 별 1개, 활동 고르기로 돌아간다
- [ ] 판 진행 중 ‘뒤로’는 두 번 눌러야 나간다(첫 번째에 “한 번 더 누르면 나가요”)
- [ ] 짝 맞추기(한자 ↔ 음뜻): 5 × 2 카드, 음뜻 카드 글자(‘아버지 부’)가 잘리지 않고, 짝이 아니면 1초 뒤 덮임, 두 판 끝나면 별
- [ ] 내 한자판: 칸을 누르면 큰 카드(한자·그림·훈음) + 음성, 바깥을 누르면 닫힘. 배운 한자 칸의 익힘 별이 문제를 풀면 바뀐다
- [ ] 그림 32장이 Safari 12에서 깨지지 않고 보인다(특히 사람 그림·孝 업기)
- [ ] 부모 모드 > 한자똑똑 설정: 배운 한자 판 8열 × 4줄, 체크 표시, ‘다음 2자 추가’·‘모두 해제’
- [ ] 과목을 10번 열고 닫아도 느려지지 않는다
- [ ] 음원(마무리 뒤): 훈음·지시문 mp3가 나온다, 비행기 모드에서도 나온다
