## 1. 진행 순서 (실제)

1. 문서 확인 → 구현 전 질문 11개(음원 폴더, 스티커 안내 이어 말하기, 다시 내기·익힘·지시문·그림 구분 등) → 모두 Claude 추천대로 결정
2. 화면 없는 로직 + Vitest: 세트 데이터 32자, 출제 주머니(문서의 테스트 4개), 보기 고르기(헷갈리는 짝 우선), 익힘 단계, 한 판 진행
3. 껍데기 보완: `audio.sayNext`(스티커 안내가 과목 첫 안내를 끊지 않게), 과목 등록 `folder`(시리즈 음원 폴더 공유), 부모 설정 `multi` 판 칸 폭·체크 표시
4. 과목 화면 6개 + 배운 한자 설정 → 첫 배포
   - 첫 배포가 `voice:check`에서 멈춤 → 개발 중 대사 `draft` 표시 규칙 추가(05 문서 15-2)
5. 아이패드에서 한자 자형·칸 확인(괜찮음) → 그림 32장(`tools/hanja-pictures.mjs`)
6. 이후 실기기 확인은 갤럭시 탭으로만(아이패드는 `checklists/ipad-checklist.md`에 쌓아 마지막에)
7. 갤럭시 확인 후 수정
   - 듣고 고르기 → 한자 찾기(음뜻 글자를 보고 한자 고르기), 짝 맞추기 한자 ↔ 음뜻, 5장씩 2줄·한자판 8칸 고정
   - 뒤로 버튼 작게, 과목 이름 ‘한자똑똑’
   - 보기 2 × 2 사지선다(기본 4개), 그림·음뜻 고르기 다시 듣기 삭제, 한자 카드는 ‘다음’으로 뒤집기 → 다음 한자
   - 한자 찾기 안내와 첫 훈음이 겹침 → `ctx.audio.sayNext`를 과목에도 열어 이어 말하기
8. 음원 77개 Typecast 제작(목소리 ‘아찌’, 훈음·뜻 normal) → 바뀐 안내 1개 다시 제작 → `voice:check -- --final` 통과
